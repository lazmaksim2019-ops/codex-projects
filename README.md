# Projects Showcase

Учебная страница «Проекты» для практического задания: список тестовых проектов, поиск, фильтрация и CRUD-операции с сохранением данных в браузере.

## Live demo

Актуальная production-версия: [codex-projects-iota.vercel.app](https://codex-projects-iota.vercel.app).

Репозиторий: [github.com/lazmaksim2019-ops/codex-projects](https://github.com/lazmaksim2019-ops/codex-projects).

## Что реализовано

- список тестовых проектов;
- поиск по названию, описанию, категории и статусу;
- фильтр по статусу;
- создание и редактирование проекта;
- удаление с подтверждением;
- валидация обязательных полей;
- сохранение изменений после перезагрузки через `localStorage`;
- responsive layout без пересечения поиска и CTA;
- состояние пустого результата и сброс фильтров.

## Стек

- React 19;
- Vite;
- JavaScript / JSX;
- CSS без UI-кита;
- `localStorage`;
- Playwright + Chromium;
- Vercel.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

## Проверка

```bash
npm ci
npm run build
npm run test:browser
```

Browser smoke tests покрывают основной пользовательский сценарий: загрузку списка, создание и валидацию, сохранение после reload, поиск, фильтрацию, empty state и responsive toolbar на 375 px и 320 px. На мобильных viewport проверяются отсутствие горизонтального overflow и пересечения поиска с CTA.

## Данные

Backend не используется. Приложение работает только с тестовыми данными, которые сохраняются в `localStorage` под ключом `projects-showcase-data-v1`.
